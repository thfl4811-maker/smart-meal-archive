# 나의 식단 아카이브

## 실제 구현 기능
- 경기도 학교 검색 및 내 학교 등록
- 등록 학교의 학교급 자동 적용
- 경기도 내 같은 학교급 비교학교 최대 3개 선택
- 조회 기간 최대 1년
- 나이스 API의 실제 중식 데이터 조회
- 기준 메뉴 및 비슷한 메뉴 포함 검색
- 기준 메뉴와 함께 편성된 주찬·부찬 빈도 분석
- 학교 수, 편성 횟수, 최근 편성일 표시
- 실제 급식 전체 식단 카드 표시
- 알레르기 번호, 열량, 영양정보 표시
- 즐겨찾기 및 식단 복사
- 선택 학교 브라우저 저장

## Vercel 배포
1. 이 폴더 전체를 GitHub 저장소에 업로드합니다.
2. Vercel에서 저장소를 Import합니다.
3. Environment Variables에 다음을 등록합니다.
   - Key: `NEIS_API_KEY`
   - Value: 본인의 나이스 Open API 인증키
4. Deploy를 누릅니다.

기존 Vercel 프로젝트에 하위 폴더로 넣는 경우 Root Directory를 이 폴더로 지정합니다.

## 참고
메뉴의 주찬·부찬 분류는 메뉴명 키워드 기반 자동 분류입니다. 학교별 메뉴 표기 방식에 따라 일부 메뉴는 다르게 분류될 수 있습니다.
